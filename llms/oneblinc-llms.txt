# OneBlinc

> OneBlinc is a US consumer fintech providing cash advances, credit-building and financial-wellness
> products to public-sector, healthcare and other essential workers underserved by traditional banks.

## Status for agents

- No OpenAPI, GraphQL SDL, AsyncAPI, Protobuf or WSDL contract is served on any OneBlinc host.
- No MCP server and no A2A agent card were found on any host (probed 2026-08-26).
- `api.oneblinc.com` is a real origin but a private backend for OneBlinc's own mobile and web clients;
  every discovery path returns a 0-byte HTTP 404.
- The marketing site, the app landing host and the customer dashboard are single-page applications whose
  edge answers HTTP 200 with an identical HTML shell for every path, so a 200 from those hosts is not
  evidence that a document exists.
- There is nothing here an agent can call.

## Products

- [BlincAdvance](https://www.oneblinc.com/products/blinc-advance): paycheck advances from $50 up to $250,
  no interest and no late fees, on an $8.99/month subscription with an optional paid instant-deposit tier.
- [BlincBoost](https://www.oneblinc.com/products/blinc-boost): monthly credit-building subscription with
  unlimited credit-score access.
- [BlincEarn](https://www.oneblinc.com/products/blinc-earn): pre-launch earn-in-your-free-time product.
- [BlincFy](https://www.oneblinc.com/products/blinc-fy): the one business-facing product — customer-
  permissioned income and employment verification data and analytics. Sold through "Schedule a Demo";
  no public developer documentation, no reference, no spec.
- [Legacy installment loans](https://www.oneblinc.com/loans): originated by BlincLoans, Inc.; the company
  states it is temporarily not accepting new loan applications.

## Known broken links

The App Store listing directs users to `oneblinc.com/terms` and `oneblinc.com/privacy-policy`. Both routes
return HTTP 200 but serve the site homepage, not the documents. The footer's Privacy Policy, Legal
Disclaimers and ISMS Policy are JavaScript modal buttons with no linkable URL.
